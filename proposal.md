# Silly Soundboard

## Repository
<https://github.com/mshark07/final-pfda-assignment>

## Description
This will be an interactive soundboard that prompts the user to click on one of the many images on the screen, which will result in a sound effect and visual effect unique to the image clicked. This is useful for anyone looking to have sound effects play at the click of a button like during livestreams, podcasts, annoying someone in a conversation, etc.

## Features
- Each image will be manipulated accordingly when hovered over or clicked on.
	- find a pygame module that has methods for shape/image manipulation and have it work when mouse interacts.
- Corresponding sound effect plays when image is clicked on. 
	- Find pygame module for sounds and have it enabled when mouse interacts.
- Corresponding visual effect is executed on screen when image is clicked on.
	- Create effects using similar methods to digital rain assignment to create visual elements that move on screen when prompted to.
- On screen volume control
	- use methods from pygame sound mixer module and tie it to an onscreen graphic that can be interacted with by the user.

## Challenges
- How to make images react to mouse movement and interaction.
- How to implement sound effects and have them executed when prompted for.
- How to implement an on screen volume controller. 

## Outcomes
Ideal Outcome:
- Have a working soundboard with a variety of buttons to click on, each with its own unique sound and visual effect that works when clicked, as well as an on screen volume controller to allow for the user to adjust volume in relation to other applications.

Minimal Viable Outcome:
- When each image is clicked on, a sound effect is executed accompanied by some sort of visual effect like the image rotating or changing size rather than something more extravagant.
